# Final Project Work

## Development and Deployment of a Web Application
### Objective:
The purpose of this assignment is to design, develop, and
deploy a complete web application that demonstrates the use
of structured navigation, modular coding practices, and
appropriate styling techniques.

### Task Description:
You are required to create a functional web application that incorporates a navigation
bar allowing users to seamlessly access different sections of the website. The application
must meet the following requirements:
1. Pages and Navigation
- Develop at least three web pages:
  1. Home Page
  2. About Us Page
  3. Contact Page
- Implement a navigation bar with links to each of these pages, ensuring smooth
navigation when links are selected.
2.Design and Layout
- Apply appropriate CSS layout techniques (e.g., Flexbox, Grid) to structure the
content.
- Incorporate icons within the navigation bar to enhance usability and aesthetics.
- Ensure that all content is properly aligned, with justified text where appropriate.
- Emphasize reusability by separating content, styling, and behavior using modular
and maintainable code.
- Link external CSS and JavaScript files rather than embedding code inline or
internally.
3. Deployment
- Research and utilize a free web hosting service (e.g., Mercantile, GitHub Pages, or
equivalent) to publish the application online.
- Provide the live link to your deployed application along with your submission.
4. Deliverables:
- Source code of the web application (HTML, CSS, JavaScript).
- A short report (5+ pages) documenting:
- The design decisions made (layout, styling, and navigation).
- The deployment process followed.
- The hosting service selected and the justification for its use.
- URL to the live deployed application.
